# Web3 Crypto Awwwards Landing Page

Fütüristik bir Web3 / kripto landing page tasarımı. Neon, uzay, premium blockchain hissi veren tek sayfalık arayüz.

## Özellikler

- Premium hero section
- Web3 metrik kartları
- DeFi / DAO / NFT / Gaming ecosystem bölümleri
- Holografik visual öğeler
- Mobil uyumlu responsive tasarım
- Sayfa içi animasyonlar

## Çalıştırma

Açık bir tarayıcıda `index.html` dosyasını açın.

Alternatif olarak:

```bash
python3 -m http.server 8000
```

Sonra tarayıcıda `http://localhost:8000` adresine gidin.
